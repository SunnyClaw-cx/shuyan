# 枢言（Shuyan）入门手册

> 面向第一次写枢言的人。读完这一份，你就能写出可用的程序。

---

## 一、五分钟上手

### 1. 运行第一个程序

新建 `你好.sy`：

```shuyan
输出("你好，世界！")
```

运行：

```bash
python sy.py 运行 你好.sy
```

输出：

```
你好，世界！
```

### 2. 变量

```shuyan
定义 姓名 = "陈工"          # 可变
常量 圆周率 = 3.14159       # 不可变
定义 年龄 = 30
定义 身高 = 1.75

输出(姓名)                  # 陈工
输出(年龄 + 1)              # 31
```

**中文标识符直接用**，不需要转写、不需要下划线：

```shuyan
定义 订单数量 = 100
定义 单价 = 12.5
定义 总金额 = 订单数量 * 单价
输出(总金额)                # 1250.0
```

### 3. 白话写法（可选）

同一件事，口语化写法：

```shuyan
设 姓名 是 "陈工"
令 圆周率 是 3.14159

说一声 `你好，{姓名}！`
```

**两种写法产出完全相同的程序**——选你顺手的即可。

## 二、基本语法

### 2.1 注释

```shuyan
# 井号注释（到行尾）
// 双斜线也可以
/* 块注释
   可以跨行 */
```

### 2.2 数据类型

| 类型 | 写法示例 | 说明 |
|---|---|---|
| 整数 | `42`、`-7`、`3万`、`一百二十` | 支持中文数词 |
| 小数 | `3.14`、`1.5e3` | |
| 文本 | `"你好"`、`'你好'` | |
| 插值文本 | `` `你好，{名字}` `` | 反引号，`{}` 内可写表达式 |
| 布尔 | `真` / `假` | |
| 空 | `空` | |
| 列表 | `[1, 2, 3]` | 可混合类型 |
| 映射 | `{"名字": "小明", "年龄": 20}` | 键值对 |

**中文数词**是枢言的特色，`三`、`一百二十`、`十亿`、`3万` 都是合法字面量：

```shuyan
输出(三 + 一百二十)         # 123
定义 本金 = 3万
输出(本金)                  # 30000
```

### 2.3 分支

```shuyan
如果 年龄 >= 18 则
    输出("成年")
否则如果 年龄 >= 12 则
    输出("少年")
否则
    输出("儿童")
结束
```

白话写法：

```shuyan
若 年龄 不小于 18，那么
    说一声"成年"
否则的话
    说一声"未成年"
完
```

### 2.4 循环

**四种循环**，按场景选：

```shuyan
# 一、计数循环（重复 N 次）
重复 5 次
    输出("第几次？")
结束

# 二、中文数词写法（等价）
重复三次
    输出("也是三次")
结束

# 三、区间循环（从…到…，**包含两端**）
重复 i 从 1 到 5
    输出(i)                 # 1 2 3 4 5
结束

# 四、遍历（列表 / 文本 / 映射）
遍历 名字 中 ["张三", "李四"]
    输出("你好，" + 名字)
结束

# 五、条件循环
定义 i = 0
当 i < 3 成立
    输出(i)
    i += 1
结束
```

白话遍历：

```shuyan
遍历 ["苹果", "香蕉"] 中的每个 水果
    说一声 水果
完
```

**跳出与继续**：

```shuyan
遍历 数字 中 [1, 2, 3, 4, 5]
    如果 数字 是 3 则
        继续                    # 跳过本次
    结束
    如果 数字 是 5 则
        跳出                    # 结束整个循环
    结束
    输出(数字)                  # 1 2 4
结束
```

### 2.5 函数

```shuyan
请 计算面积(长, 宽)
    返回 长 * 宽
结束

输出(计算面积(6, 7))            # 42
```

**默认参数**、**可变参数**：

```shuyan
请 打招呼(名字, 问候 = "你好")
    返回 问候 + "，" + 名字
结束

输出(打招呼("小明"))                    # 你好，小明
输出(打招呼("小红", "早上好"))          # 早上好，小红

请 求和(...所有数字)
    定义 总计 = 0
    遍历 数字 中 所有数字
        总计 += 数字
    结束
    返回 总计
结束

输出(求和(1, 2, 3, 4, 5))              # 15
```

**闭包**（函数记住定义时的环境）：

```shuyan
请 创建计数器()
    定义 次数 = 0
    请 加一()
        次数 += 1
        返回 次数
    结束
    返回 加一
结束

定义 计数 = 创建计数器()
输出(计数())    # 1
输出(计数())    # 2
输出(计数())    # 3
```

**高阶函数**（函数可以像数字、文本一样传参）：

函数在枢言里是**一等公民**：能赋给变量、能当参数传、能当返回值。
标准库据此提供一组高阶函数，**不必**再手写 `当` + `入列` 的循环。

```shuyan
定义 数据 = [1, 2, 3, 4, 5]

输出(筛选(数据, 函数(x) 返回 x > 2 结束))        # [3, 4, 5]
输出(映射列表(数据, 函数(x) 返回 x * x 结束))    # [1, 4, 9, 16, 25]
输出(归约(数据, 函数(a, b) 返回 a + b 结束, 0))  # 15
输出(任何(数据, 函数(x) 返回 x > 4 结束))        # 真
输出(全部(数据, 函数(x) 返回 x > 0 结束))        # 真
```

命名函数同样可传：

```shuyan
请 是偶数(x)
    返回 x % 2 == 0
结束

输出(筛选(数据, 是偶数))                          # [2, 4]
输出(计数依据(数据, 是偶数))                      # {假: 3, 真: 2}
```

最常用的是**按字段排序与分组** —— 用 `结构体` + `排序依据` 表达：

```shuyan
类型 商品 = { 名称: 文本, 单价: 整数, 类别: 文本 }

定义 清单 = [
    商品(名称 是 "甲", 单价 是 30, 类别 是 "工具"),
    商品(名称 是 "乙", 单价 是 10, 类别 是 "耗材"),
    商品(名称 是 "丙", 单价 是 20, 类别 是 "工具"),
]

请 取单价(货)
    返回 货.单价
结束

请 取类别(货)
    返回 货.类别
结束

定义 按价 = 排序依据(清单, 取单价)
输出(按价[0].名称)                       # 乙

输出(计数依据(清单, 取类别))             # {工具: 2, 耗材: 1}
输出(分组依据(清单, 取类别))             # {工具: [商品{...}, ...], 耗材: [...]}
```

速查（完整签名见 [`STDLIB.md`](STDLIB.md)）：

| 函数 | 作用 | 集合可传 |
|---|---|---|
| `筛选(集合, 判定)` | 保留判定为真的元素 | 列表 / 文本 / 映射 |
| `映射列表(集合, 变换)` | 逐元素变换 | 列表 / 文本 / 映射 |
| `归约(集合, 累积, 初值?)` | 折叠为单值 | 列表 / 文本 / 映射 |
| `任何` / `全部` | 是否存在 / 是否全满足 | 列表 / 文本 / 映射 |
| `查找首个(集合, 判定)` | 首个满足者，无则 `空` | 列表 / 文本 / 映射 |
| `排序依据(集合, 取键, 倒序?)` | 稳定排序 | 列表 / 文本 / 映射 |
| `分组依据(集合, 取键)` | 键 → 元素列表 | 列表 / 文本 / 映射 |
| `计数依据(集合, 取键)` | 键 → 出现次数 | 列表 / 文本 / 映射 |
| `映射值(映射, 变换)` | 保留键，变换值 | 映射 |

> **注意事项**
> - 真值判断与 `如果` **完全一致**：`0`、`""`、`空列表`、`空映射` 都算假。
> - `归约` 对空列表**必须**给初值，否则明确报错（不会悄悄返回空值）。
> - 传的不是函数时会得到「第 2 个参数应该是函数」的明确提示。

### 2.6 异常处理

```shuyan
试
    抛出 {"类型": "业务错误", "信息": "库存不足"}
捕获 异常
    输出("出错了：" + 异常["信息"])
最终
    输出("无论如何都会执行")
结束
```

抛出值可以是**任意类型**（文本、数字、映射都行）。

### 2.7 结构体与枚举

枢言用**同一个 `类型` 关键字**声明结构体、枚举和类型别名 ——
看花括号里有没有 `:` 即可区分，无需记多个关键字。

#### 结构体（字段带类型）

```shuyan
类型 点 = {横: 整数, 纵: 整数}

定义 甲 = 点(横 是 3, 纵 是 4)      # 具名字段构造，**顺序无关**
定义 乙 = 点(纵 是 4, 横 是 3)      # 写成这样也行，与甲完全相等

输出(甲.横)                          # 3
输出(甲)                             # 点{横: 3, 纵: 4}（恒按声明顺序）
输出(甲 等于 乙)                     # 真
```

字段可以嵌套结构体，也可以写访问式构造：

```shuyan
类型 线段 = {起点: 点, 终点: 点}
定义 一条 = 线段(起点 是 点(横 是 0, 纵 是 0), 终点 是 甲)
```

写错字段名或漏字段，**编译期**就报错并给出候选：

```shuyan
点(横 是 3, 高 是 4)     # D3017：字段「高」不存在；是想写「纵」吗？
点(横 是 3)              # D3017：缺少字段「纵」
```

#### 枚举（成员不带类型）

```shuyan
类型 星期 = {一, 二, 三, 四, 五, 六, 日}
类型 单据状态 = {待审核, 已批准, `处理中`, 已完成}

定义 今天 = 星期.三
输出(今天)               # 星期.三
输出(今天.名称)          # 三
输出(今天.序号)          # 3（从 1 起）

若 今天 等于 星期.三 则
    输出("今天是周三")
结束
```

两个要点：

- **`序号`** 与 **`名称`** 是枚举成员的属性（`成员.序号` / `成员.名称`）。
- **`处理中` 要加反引号**：`中` 是单字联结词，不加会被切成 `处理` + `中`。
  反引号是逃生舱，强制整体保留（与变量名同一机制）。

枚举成员名可用中文数词（`星期.一`）—— 匹配按**源码原文**，不会与数字 `1` 混淆。

#### 类型别名

```shuyan
类型 标识 = 整数
类型 编号表 = [文本]
```

### 2.8 多文件工程

把代码拆到多个 `.sy` 文件，用 `引入` 组织。有两种引入方式：

```shuyan
# 方式一：整模块引入 → 命名空间绑定
引入 "工具"
输出(工具.平方(3))

# 方式二：按名引入 → 直接绑定
引入 { 平方, 立方 } 从 "工具"
输出(平方(3))
```

**路径规则**：`引入 "工具"` 找的是**主脚本所在目录**下的 `工具.sy`
（不是当前工作目录）—— 这样程序换目录运行，行为不变。

一个模块的完整示例：

```shuyan
# 文件：工具.sy
请 平方(n)
    返回 n * n
结束

类型 点 = {横: 整数, 纵: 整数}
```

```shuyan
# 文件：主程序.sy
引入 "工具"
定义 原点 = 工具.点(横 是 0, 纵 是 0)     # 类型也能跨模块用
输出(工具.平方(3))                        # 9
```

> 完整可运行的多文件样例见 [`projects/库存管理/`](../projects/库存管理/)，
> 三个文件构成一个真实的库存业务程序。

### 2.9 中文句法的边界（**必读**）

中文没有词间空格，枢言用固定规则切分。绝大多数情况符合直觉，但有一条边界要记住：

**单字联结词（是 / 为 / 中 / 从 / 到 / 里 / 叫）若要作语法词，两侧要有空格或标点。**

```shuyan
定义 年龄 是 20      # ✅ 正确
定义年龄是20         # ⚠️ `是` 会黏进标识符 → 需写成 `年龄 是 20`
                    #    （更好的是直接用 `=`）

定义 数据中台 = 1     # ✅ `中` 不会误切（数据中台 是完整标识符）
```

**为什么这样设计**：如果允许 `中` 在汉字中间随意切分，
`数据中台`、`期中成绩`、`其中原因` 这些**极常见的词**都会被切坏。
规范选择**规则确定**（宁可要求加空格），而不是**统计猜测**。

**多字词不受影响**，可自由紧贴：

```shuyan
定义年龄 = 20           # ✅ `定义` 是两字词，切分安全
如果条件 则              # ✅
遍历名单中的每个名字      # ✅ 白话遍历
```

**单字引导词（令 / 当 / 若 / 让 / 设 / 试 / 请）也有边界。**
它们只有在「后面紧跟另一个**多字**关键字」时才融合切分，
所以下面这些**常见词不会被切坏**：

```shuyan
定义 清单 = 系统.当前目录()    # ✅ `当前目录` 完整（不会切成 `当` + `前目录`）
定义 设备 = "设备清单"          # ✅ 不会被 `设` 切开
定义 记录 = "试验记录"          # ✅ 不会被 `试` 切开
定义 请假 = 真                # ✅ 不会被 `请` 切开
```

**汉字段后面紧接拉丁字母/数字也算同一个名字**，这一点在访问内置成员时很重要：

```shuyan
引入 "编码"
输出(编码.编码Base64("你好"))    # ✅ `编码Base64` 是一个完整名字
输出(编码.解码Base64("5L2g5aW9"))
```

**实在要用关键字作变量名**——用反引号：

```shuyan
定义 `定义` = "这是一个名叫「定义」的变量"
```

## 三、中文处理的特别说明

枢言对中文的处理有两处与直觉不同，**务必记住**：

### 3.1 长度按字符算，不按字节

```shuyan
输出(长度("你好"))        # 2  （不是 6 字节）
输出(长度("a你b好"))      # 4
```

### 3.2 对齐按显示宽度算（汉字 = 2 列）

```shuyan
输出(文本.填充("你好", 10))
# 输出 "你好" + 6 个空格（2 个汉字占 4 列，补到 10 列）
```

这条规则让终端表格对齐不出错。`文本.显示宽度("你好")` 返回 4。

### 3.3 全角符号自动识别

```shuyan
输出（"你好"）            # ✅ 全角括号能识别
定义 甲 ＝ 1              # ✅ 全角等号能识别
```

但**规范建议用半角**，`sy 检查` 会提醒。意图不明的标点（`《》`、`——`、`……`）会**明确报错**，
不会静默处理。

### 3.4 中文数词

```shuyan
输出(三)                  # 3
输出(一百二十)            # 120
输出(十五)                # 15
输出(一九九八)            # 1998（连续数字按拼接）
输出(3万)                 # 30000
```

## 四、标准库速查

无需 `引入` 的核心函数（详见 `STDLIB.md`）：

```shuyan

# 类型与转换

# 文本
长度(文本)  截取(文本, 起, 长)  查找(文本, 子串)  替换(文本, 旧, 新)

# 列表

引入 "编码"
输出(编码.编码Base64("你好"))    # 5L2g5aW9

引入 "加密"
输出(加密.SHA256("密码"))

引入 "正则"
输出(正则.是否匹配("abc123", "\\d+"))    # 真
```

## 六、看懂报错

枢言的报错包含五要素：**行号、列号、错误码、源码位置、修复建议**。

```
第 5 行，第 9 列：语义错误（D3004）
  不能把「文本」赋值给「整数」变量「年龄」。

    5 |     年龄 是 "二十岁"
      |            ^^^^^^^^
  · 此处得到的类型是「文本」
  → 建议：改用 整("二十岁")，或把 年龄 声明为 文本。
```

**未定义变量**会给出拼写候选：

```
第 3 行，第 1 列：语义错误（D3005）
  没有定义「计树」。

  3 | 输出(计树)
    | ^^^^

  → 建议：你是不是想写：计数
  → 建议：用 `定义 计树 = ...` 先声明它
```

**错误码速查**：

| 前缀 | 含义 |
|---|---|
| `D1xxx` | 词法错误（字符串未闭合、非法字符） |
| `D2xxx` | 语法错误（缺少 `结束`、括号不匹配） |
| `D3xxx` | 语义错误（未定义、类型不符、参数个数） |
| `D4xxx` | 运行时错误（除零、下标越界、未捕获异常） |
| `W4xxx` | 代码提醒（未使用变量、全角括号、超长行） |

**提醒（W 开头）不影响运行**，只是建议。

## 七、常见问题

**Q：为什么 `2 的 10 次方` 不能算？**
A：中文的「的」字太常用（`我的名字`、`系统的状态`），定为运算符会造成大量歧义。
请用 `次方(2, 10)` 或 `2 ^ 10`。

**Q：`定义年龄是20` 为什么报错？**
A：`是` 是单字联结词，紧贴汉字时不切分（否则 `数据中台` 会被切坏）。
写成 `定义 年龄 是 20`，或直接用 `定义 年龄 = 20`。

**Q：可以写英文吗？**
A：可以。`let x = 1`、`if x > 0 { print(x) }` 都合法。关键字有拉丁别名。

**Q：字符串里的全角标点会被改吗？**
A：不会。字符串内容是**数据**，原样保留。`"你好，世界！"` 输出就是 `你好，世界！`。

**Q：怎么调试？**
A：目前用 `输出(...)` 打印中间值，配合 `sy 检查` 做静态检查。
交互式调试器在路线图 P2 阶段。
